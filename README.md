# Jitwar Jha — Personal Portfolio

> Built with React, Vite, and custom CSS inspired by the editorial monochrome portfolio design by Huy Phan on Dribbble.

## 🚀 Live Preview
Run:
```bash
npm install
npm run dev
```
Or view the production build:
```bash
npm run preview
```

## 🎨 Features
- **Editorial Typography & Layout**: Authentic reproduction of the serif/sans-serif combination, numbering, asterisk status indicators, and minimalist aesthetic.
- **Cinematic Curtain Transition**: Fullscreen expanding curtain wipe with simulated loader (0% → 100%) when navigating between sections.
- **Interactive Character Mascot**: 4 cycling animation states (Idea Lightbulb, Growth Plant, Soccer Ball, Game Controller) extracted directly from the video template.
- **Horizontal Works Gallery**: Grouped by year (2026, 2025, 2024) with interactive modal drawer for system architecture deep dives.
- **Resume Content Integration**: Full integration of KisanSetu (SIH 21st rank), Mess Management System, LeetCode (35+ solved), education at PIET Jaipur, and complete technical skill sets.
- **Responsive & Interactive**: Custom cursor dot/follower, responsive grid layout for mobile and desktop, and direct contact avenues.
